# ADDON.md compatibility entry point

The canonical session handoff is [`addon.md`](addon.md).

This uppercase compatibility file exists intentionally because older project instructions referred to `ADDON.md`. On case-sensitive systems that path previously failed even though the research content existed as `addon.md`.

**Do not duplicate the 50+ kB research handoff here.** Keeping one canonical content file avoids divergence while preserving the historical path as a working entry point.

New sessions should read, in order:

1. `AGENTS.md`
2. `README.md`
3. `docs/REPLICATION_STATUS.md`
4. `addon.md`
5. `STATE.md`
6. `docs/sources.md`
7. `docs/research/source-basis.md`
8. `docs/research/evidence_matrix.tsv`
9. `docs/research/machines.yaml`
10. `docs/research/provenance-schema.yaml`
11. the subsystem-specific research files relevant to the task.
