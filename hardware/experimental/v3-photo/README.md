# Experimental V3 photo interpretation assets

These assets are generated by `cad/generate_v3_photo_interp.py`.

## Purpose

This branch captures a **more photo-faithful external arrangement** of the first small Testatika machine shown by Marinov. It is intended for comparative reconstruction work, not for claiming a final solved circuit.

## Contents

After the materialization workflow runs:

- `stl/` — printable or inspectable part files for the V3 interpretation;
- `step/` — editable CAD exchange files for the same V3 parts;
- `complete-model/` — assembled V3 external-geometry model.

## Important caveat

The V3 model improves the visible arrangement, but it does **not** solve:
- exact hidden wiring;
- exact material composition of dark grids;
- the internal structure of the top "crystal" module;
- the historical output circuit.

## Recommended use

Use V3 as an **experimental geometry branch** while continuing to keep V2 as the baseline evidence-led reference.
