# V3 photo branch — small machine pixel interpretation

This directory contains the **third-pass, photo-led re-analysis** of the first small Testatika machine discussed by Stefan Marinov.

## Scope

V3 does **not** replace the baseline V2 reconstruction. Instead, it adds:

1. a tighter reading of the high-resolution frontal photograph;
2. a more explicit distinction between **what is actually visible**, **what Marinov explicitly states**, and **what remains interpretive**;
3. an additional **experimental external-geometry CAD model** under `hardware/experimental/v3-photo/`;
4. a provisional **functional schematic**, **node map**, and **connection plan** suitable for future experiment branches.

## Files

| File | Purpose |

| `pixel-analysis.md` | full visual and source-based analysis |
| `functional-model.md` | working interpretation of subsystems and charge flow |

| `../../../hardware/experimental/v3-photo/` | generated STL / STEP outputs |

## Key methodological rule

**Do not read hidden electrical function directly out of visible color.** The photo can justify geometry, separation, adjacency, approximate scale and symmetry. It cannot by itself prove hidden conductivity, internal dielectric layering, polarity, or semiconductor behaviour.

## Status

- **Geometry:** improved external fidelity versus V2, still approximate.
- **Electrical circuit:** provisional only.
- **Historical confidence:** medium for visible external arrangement; low for concealed internals.
