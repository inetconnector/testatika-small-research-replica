# Seitliche „Pots“

Die kleinen Seitenmodule werden in Marinovs Korrespondenz als einfache Kondensatorstruktur interpretiert:
- äußere zylindrische Elektrode/Gitter;
- isolierende Kunststoff-/Acrylschicht;
- innere Elektrode als dicke Kupferspirale.

V2 trennt deshalb:
1. `pot_outer_shell` — mechanische Hülle;
2. `pot_grid_former` — Träger für echte Metallgaze;
3. `pot_acrylic_sleeve_jig` — Maßkörper; für elektrische Versuche durch echtes Acrylrohr ersetzen;
4. `pot_spiral_mandrel` — Wickelkörper für dickeren Kupferdraht;
5. `pot_terminal_lid`.

Die Kupferspirale wird **nicht** als Tesla-Sekundärspule behandelt.
